Test Suites

Automated test suites

The Playwright coverage is split into two suites. The smoke suite is a fast subset that runs on every push to fail fast on the critical flows, while the full regression suite runs the complete set of UI tests headlessly against Chromium desktop, Firefox desktop and a Pixel 5 mobile viewport. The numbers below come from the committed CI report data (ui-results.json) - no tests execute on this page.
